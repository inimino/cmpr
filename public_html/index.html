cmpr Event Visualizations

Interactive visualizations of the event system tracking agent activity, metrics, and temporal trends.

Timeline

Event Timeline
Scatter plot of all event snapshots over time, showing agent runs and work sessions.

Metrics

Unreferenced Blocks
Track blocks that are not reachable from #root over time.
 Hub Blocks
Number of hub/overview blocks in the codebase.
 Event Count
Total events tracked in snapshots over time.

Statistics

Snapshot Statistics
Statistical analysis of event patterns, agent activity, and snapshot distribution.

About

These visualizations are generated from the cmpr event system, which tracks wants, agent activity, and metrics over time.

To regenerate:

dist/cmpr --print-code '#generate_timeline_html' | bash > public_html/event_timeline.html
dist/cmpr --print-code '#generate_metric_plot' | bash -s unreferenced > public_html/metric_unreferenced.html
dist/cmpr --print-code '#generate_visualization_index' | bash > public_html/index.html
